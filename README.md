# Проект для хакатона Альфа-Банк Hack&Change 2025: "Модель дохода"

## О проекте

Данный проект представляет собой AI-решение для прогнозирования дохода клиентов Альфа-Банка. На основе точного прогноза система формирует персональные рекомендации по финансовым продуктам, что позволяет банку повысить качество обслуживания, минимизировать риски и повысить эффективность кросс-продаж.

**Основные компоненты решения:**
- **ML-модель:** Предсказывает доход клиента, оптимизирована по метрике WMAE.
- **Бэкенд:** API для взаимодействия с моделью.
- **Фронтенд:** Веб-интерфейс для сотрудников банка с визуализацией прогнозов, объяснением модели (SHAP) и персональными рекомендациями.
- **Прототип:** Рабочий сервис, демонстрирующий полный цикл от прогноза до бизнес-рекомендации.

## Инструкция по запуску (ML-часть)

Для запуска и тестирования Machine Learning части проекта выполните следующие шаги:

1. **Клонируйте или скачайте проект**
   - https://drive.google.com/drive/folders/1UDq62-Mk7YNxZJz_TUObI3VnEpQ6AGGw?usp=sharing
   - Убедитесь, что у вас есть папка `HC` со всей структурой, приведенной выше.

3. **Создайте и активируйте виртуальное окружение (рекомендуется)**
   
Для Windows (Command Prompt):
```bash
python -m venv venv
venv\Scripts\activate
```


Для Windows (PowerShell):
```bash
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Для Linux/macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```



3. **Установите необходимые библиотеки**
Убедитесь, что у вас установлен Python (рекомендуется версия 3.9+). Затем установите зависимости, соблюдая версии:
```bash
pip install joblib==1.5.2 lightgbm==4.6.0 numpy==2.0.2 pandas==2.2.2 scikit-learn==1.6.1
```

4. **Запустите ноутбуки для обработки данных и обучения модели**
Запустите Jupyter Notebook/Lab и выполните ячейки в строгом порядке:

- **Запустите `notebooks/01_analysis_processing.ipynb`**
  - Этот ноутбук выполняет первичный анализ данных, предобработку и генерацию признаков.

- **Запустите `notebooks/02_model_training.ipynb`**
  - Этот ноутбук обучает финальную модель (LightGBM с квантильной регрессией) на подготовленных данных.

5. **Результаты работы**
После успешного выполнения ноутбуков:
- **Обученная модель** будет сохранена в файл `models/trained_model_lgbm_quantile.joblib`.
- **Файл с прогнозами** для тестовой выборки будет сохранен как `models/trained_model_lgbm_quantile.csv` и готов к отправке на платформу хакатона для оценки по WMAE.
