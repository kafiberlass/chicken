# Bank AI — прогноз дохода клиентов банка

Веб-интерфейс AI-сервиса, который прогнозирует доход клиента банка и объясняет,
какие факторы повлияли на прогноз. Проект сделан командой на хакатоне
[название хакатона, ноябрь 2025]. Я отвечала за фронтенд: дизайн и реализацию интерфейса.

**Демо:** [ссылка после деплоя] · с `?fail` в адресе показывается экран ошибки

## Что умеет

- Дашборд с ключевыми метриками модели и списком клиентов
- Поиск клиента по имени или ID
- Карточка клиента: текущий и прогнозируемый доход, достоверность прогноза
- Факторы влияния на прогноз (SHAP-значения)
- Светлая и тёмная тема с сохранением выбора

## Стек

React 18, TypeScript, Vite. Без UI-библиотек и сторонних стейт-менеджеров.

## Как устроена работа с данными

```
компонент → useApi (хук) → clientApi / predictionApi → request() → fetch
                                                                 ↘ mock (если нет бэкенда)
```

- **`src/api/http.ts`** — единая функция `request()`. Если в `.env` задан
  `VITE_API_URL`, запросы уходят на бэкенд через `fetch`. Ошибки сервера
  превращаются в `ApiError` с понятным сообщением.
- **`src/api/mock.ts`** — встроенный мок-бэкенд для демо без сервера. Отвечает
  настоящими объектами `Response` с задержкой сети, поэтому остальной код
  не знает, что данные ненастоящие.
- **`src/hooks/useApi.ts`** — хук загрузки: состояния `loading` / `error`,
  повтор запроса и отмена через `AbortController`. Если пользователь быстро
  переключает клиентов, прошлый запрос отменяется, и устаревший ответ не
  перезапишет свежий.

## Запуск

```bash
cd frontend
npm install
npm run dev
```

Без настроек приложение работает на мок-данных. Чтобы подключить бэкенд:

```bash
cp .env.example .env
# в .env: VITE_API_URL=http://localhost:8000
```

Сборка: `npm run build` (сначала проверка типов, потом сборка в `dist/`).

### API, которое ожидает фронтенд

| Метод | Адрес | Ответ |
|---|---|---|
| GET | `/clients` | список клиентов |
| GET | `/stats` | метрики модели |
| GET | `/clients/:id/prediction` | прогноз и SHAP-факторы |
